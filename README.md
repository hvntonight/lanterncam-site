# LanternCam site

Public product, support and privacy pages in Simplified Chinese and English. No analytics or external scripts. Version 1.0 (14) was submitted for App Store review on 2026-10-31. It is free and configured to release after approval; not publicly available yet.

The application source is maintained separately in `hvntonight/lanterncam-ios`. No private signing material, review contacts, pairing data, or real camera footage belongs in this repository.
